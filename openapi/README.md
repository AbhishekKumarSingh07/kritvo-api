# openapi

`openapi.json` here is the API contract consumed by `kritvo-web` (`pnpm gen:api`).

- Generated by `uv run kritvo-openapi` (added in TASK-001); never edit it by hand.
- Commit it in the same PR as any API change. CI fails if it is stale.
- Changes must be backward-compatible until `kritvo-web` no longer uses what you remove.
