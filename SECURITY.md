# Security policy

- Report suspected vulnerabilities privately to the project lead (add the contact address here). Do not open public issues for security problems.
- Never commit secrets. If one is committed, rotate it immediately, then remove it from history with the project lead's help; rotating comes first because the old value must be treated as leaked.
- Incident handling follows HLD section 11 (CERT-In 6-hour reporting, DPDP breach steps).
