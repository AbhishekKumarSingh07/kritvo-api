# Review records

Keep a record for design reviews and for any code review that finds Critical or Major issues, so decisions and fixes stay traceable.

- File name: `YYYY-MM-DD-<TASK-###>-<short-topic>.md`, copied from [TEMPLATE.md](TEMPLATE.md).
- Link the record from the PR description.
- Routine PR comments stay on GitHub; they do not need a file here.
