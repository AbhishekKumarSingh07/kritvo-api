# Architecture Decision Records

An ADR records one significant decision, the options considered and the consequences. Create one with `/adr-new "<title>"` in Claude Code.

Rules: statuses are Proposed, Accepted, Rejected, Deprecated or Superseded by ADR-XXXX. Once Accepted, an ADR is never edited except to change its status line; a changed decision gets a new ADR.
